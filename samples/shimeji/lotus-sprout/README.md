# 小莲芽 — 本地 Shimeji 测试包

原创 Q 版植物精灵，透明底 PNG（1254×1254），用于验证现有 Shimeji 加载和状态动画。
本目录是默认的本地测试素材，不在应用资源根内，不随发行包安装，不替换莲花球回退。

## 使用

在设置中将桌宠外观切为 Shimeji，然后在模型管理中导入本目录，选择
「小莲芽（本地测试）」。导入后复制到应用数据目录的 `shimeji/lotus-sprout/`；
删除模型只会删除导入副本，仓库原文件保留。切回莲花球可停止本次测试。
无已保存的模型选择时，现有加载器会使用扫描到的第一个包；有其他包时请显式选择。

七个状态分别映射到 Stand、Work、Sit、Bouncing、Tripping、Pinched、Falling。
目前共用一张立绘，以 ImageAnchor 的轻微位移表现呼吸、工作、等待、跳跃和抖动；
这不是多表情完整动画。所有帧速度为零，不会自动走动窗口。拖拽姿态保持静止，
系统减少动态效果或关闭桌宠动画时由现有运行时停止播放。

## 来源与使用范围

`img/LotusSprout/sprout.png` 于 2026-10-29 使用内置 imagegen 生成，
未使用第三方角色参考或外部模型素材。XML 与 pet.json 为本项目编写。
本包当前仅用于本项目本地开发与测试；正式随包分发前需单独确认资源许可策略。

生成提示：原创小莲芽，Q 版植物精灵，圆润米白大头、深色眼睛、淡腮红，头顶薄荷色
莲花苞，青绿色叶片衣服、小手短脚；友善站姿、略朝右，完整角色居中，透明背景，
清晰深色轮廓，缩小到 128 像素仍可辨认；无文字、商标、水印、道具或地面阴影。

`ctest --test-dir build -R '^shimeji$' --output-on-failure` 会校验本包的七种
状态动作、引用图片的 PNG 签名和静止窗口约束；测试只读取仓库素材，不读用户模型目录。
